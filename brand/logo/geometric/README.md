# ECHO ECHO geometric logo

Two ripples and a teal core that together read as an E, drawn only from strokes, with no font and no third-party artwork.

| File | Use |
|---|---|
| `echoecho-icon-light-256.png` | Cashfree checkout logo (transparent, for light backgrounds) |
| `echoecho-icon-light-1024.png`, `echoecho-icon-dark-*.png` | Icon for light or dark backgrounds |
| `echoecho-tile-*.png` | Solid tile for any background |
| `echoecho-lockup-light-512h.png`, `echoecho-lockup-dark-512h.png` | Icon with the wordmark |
| `*.svg` | Editable source of each |

Colours: deep purple `#4C1D95`, electric violet `#7C3AED`, teal `#14B8A6`.

The site still uses `brand/logo/echoecho-logo-original.jpeg`. No trademark search has been done on this mark.
